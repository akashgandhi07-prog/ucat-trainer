# Product review, 22 September 2026

Reviewed the current repository, recent commits, the live SJT hub and the SJT content/import path. This is not a fresh full penetration test, production database audit or complete mobile accessibility audit.

## What has improved

Recent changes address reported question errors, repeated questions, inconsistent answer positions, misleading distortion wording, planner duplication and sign-in migration, profile-save permissions, and missing links to the DM and NOT/EXCEPT trainers. Question content is increasingly driven by feedback rather than just expanded in volume. The site also now has a configured Content Security Policy.

## Concrete local changes in this review

- Created 12 SJT draft scenarios with 44 response items and a readable review pack; no production import or publication.
- Added a reusable structural validator, import round-trip checks, mutation checks and export-freshness checking; connected the gate to CI.
- Preserved scenario-level GMC references during Question Lab import.
- Corrected SJT FAQ text that called SJT the fifth subtest and described ranking as one total mark when the quiz awards two.
- Labelled scoring as this trainer's system rather than a promise of official band equivalence.
- Removed blanket advice that non-emergency learning/teamwork cannot be very important and clarified independent rating.
- Corrected conflicting authoring specs. Kept the existing question source and production seed unchanged.
